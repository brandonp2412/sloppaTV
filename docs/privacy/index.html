sloppaTV

Privacy Policy

Last updated: 10 September 2026

Short version: the sloppaTV developer does not collect your personal information. The app talks directly to the Jellyfin server you choose and stores the session information it needs locally on your Android TV device.

sloppaTV is an independent Android TV client for Jellyfin. This policy explains what information sloppaTV handles and, in particular, what the sloppaTV developer does and does not collect.

Information collected by the developer

The sloppaTV developer does not collect personal information through the app.

sloppaTV contains no advertising SDKs, analytics SDKs, tracking SDKs, crash-reporting services, developer-operated telemetry, or developer-operated cloud backend. The developer does not sell, rent, share, or otherwise receive personal data from sloppaTV users.

Information handled locally by sloppaTV

To connect to a Jellyfin server, sloppaTV handles information supplied by the user or returned by that Jellyfin server. This can include:

  • Jellyfin server address;
  • username;
  • Jellyfin user identifier;
  • Jellyfin access token or Quick Connect authorization;
  • a locally generated device identifier; and
  • sloppaTV settings and preferences.

Saved account/session information and settings are stored in the app's private storage on the Android TV device so the user can remain signed in. This information is not sent to the sloppaTV developer.

Communication with your Jellyfin server

When a user signs in, browses a library, changes watched or favourite state, selects tracks, requests metadata operations, deletes media where permitted, or plays media, sloppaTV communicates directly with the Jellyfin server selected by that user.

Depending on the action, this communication can include authentication information, library metadata, artwork requests, playback requests, playback progress, watched/favourite changes, subtitle and audio selections, metadata refresh requests, and user-initiated deletion requests.

sloppaTV does not operate an intermediary service and does not receive this Jellyfin traffic. The Jellyfin server operator controls that server's own logging, retention, security, and privacy practices.

Data sharing

sloppaTV does not share user information with advertisers, analytics companies, data brokers, or the sloppaTV developer.

Information is sent only as needed to the Jellyfin server chosen by the user, and to network destinations explicitly required by user-requested playback or external-player actions.

Permissions

sloppaTV requests Internet access so it can connect to Jellyfin servers and stream media. It does not request location, contacts, camera, microphone, advertising identifier, or broad storage permissions.

Security

Local session information is stored in Android app-private storage. Network security depends on the Jellyfin server configured by the user. Users should prefer HTTPS for remote or untrusted networks and keep their Jellyfin server secured and up to date.

Retention and deletion

The sloppaTV developer does not retain user data because the developer does not receive it.

Users can remove saved Jellyfin accounts from within sloppaTV. Uninstalling sloppaTV removes its locally stored app data according to Android's normal app-data behaviour. Data stored by a Jellyfin server is controlled by that server's operator and must be managed there.

Children

sloppaTV is a general-audience media player and is not designed specifically for children. Media availability and age suitability are determined by the user's Jellyfin server, account, and server operator.

Changes to this policy

If sloppaTV's data-handling behaviour materially changes, this policy will be updated before or alongside the relevant app release. The date at the top of this page identifies the current version.

Contact

Privacy questions can be raised through the sloppaTV issue tracker. The source code is public on GitHub.
