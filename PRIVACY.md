# sloppaTV Privacy Policy

Last updated: 5 September 2026

sloppaTV is an independent Android TV client for Jellyfin.

## Data handled by the app

sloppaTV does not contain advertising, analytics, tracking SDKs, crash-reporting services, or developer-operated telemetry. The developer does not collect or sell personal data through sloppaTV.

To connect to a Jellyfin server, the app handles the server address and the credentials or Quick Connect authorization supplied by the user. Authentication details are sent directly to the Jellyfin server selected by the user. After authentication, sloppaTV stores the Jellyfin server address, username, user identifier, access token, device identifier, and app settings locally on the Android TV device so that the user can remain signed in.

When the user browses or plays media, sloppaTV communicates directly with the selected Jellyfin server. This can include library metadata, artwork, playback requests, playback progress, watched/favourite changes, subtitle and audio selections, metadata refresh requests, and media deletion requests initiated by the user where the Jellyfin account permits them.

sloppaTV does not operate a cloud service and does not receive this Jellyfin traffic. The privacy and retention practices of the Jellyfin server are controlled by that server's operator.

## Storage and deletion

Saved Jellyfin sessions and app settings are stored locally in the app's private storage on the device. Users can remove saved Jellyfin accounts from within sloppaTV. Uninstalling sloppaTV removes its locally stored app data according to Android's normal app-data behaviour.

## Permissions

sloppaTV requests Internet access so it can connect to Jellyfin servers and stream media. It does not request location, contacts, camera, microphone, advertising identifier, or storage permissions.

## Children

sloppaTV is a general-audience media player and is not designed specifically for children. Media availability and age suitability are determined by the user's Jellyfin server and account.
